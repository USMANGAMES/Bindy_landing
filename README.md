# Bindy Landing

Одностраничный промо-лендинг стартапа **Bindy** — PWA-карты городской чистоты для Ташкента. Сайт рассказывает о поиске урн, Vision AI для обработки фото, пользе для города и предложении для B2B-партнёров.

## Запуск

Это статический сайт без зависимостей и сборки. Откройте [index.html](./index.html) в браузере или запустите локальный сервер:

```bash
python3 -m http.server 4173
```

После этого сайт будет доступен по `http://localhost:4173`.

## Форма обратной связи — Formspree

Форма внизу сайта подготовлена для Formspree. После создания формы в [Formspree](https://formspree.io/) скопируйте её ID и замените `YOUR_FORM_ID` в `index.html`:

```html
<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
```

Например, при ID `xqkrypzw` итоговый адрес будет `https://formspree.io/f/xqkrypzw`. Тема отправляемого письма уже задана: «Новая заявка на альфа-тест Bindy».

## Адаптивность

Лендинг рассчитан на desktop, tablet и mobile. Основные переходы: `1000px`, `800px`, `620px` и `420px`. На узких экранах навигация и декоративная графика упрощаются, сетки становятся одноколоночными, а форма не выходит за границы экрана.
